# Sam'Space Flutter App

Native Flutter client for the Sam'Space offline-first planner. It uses Riverpod, GoRouter, Dio, SQLite, Flutter Secure Storage, File Picker and Image Picker. The Next.js web/PWA app and its API remain separate and unchanged.

See the repository's [MOBILE_SETUP.md](../MOBILE_SETUP.md) for prerequisites, API configuration, run/test commands, Android builds, signing, and current feature limits. See [API_DOCUMENTATION.md](../API_DOCUMENTATION.md) for the current API contracts used by mobile.
